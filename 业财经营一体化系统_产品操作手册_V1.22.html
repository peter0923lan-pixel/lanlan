阅读说明

本手册以当前系统可见页面和已实现业务规则为准，用于日常操作、培训和上线前验收。金额在各页面遵循其标注口径；经营驾驶舱和报表中心统一使用人民币折算口径。

核心业务闭环：基础档案 → 客户 → 合同与 SKU → 附件归档/签约确认 → 回款计划 → 到账与分配 → 收入确认 → 目标预测与经营分析。
1. 角色与权限2. 首页与经营驾驶舱3. 客户管理4. 合同台账、双币种与附件5. 回款管理与到账通知单6. 收入管理7. 预测与目标、报表中心8. 基础档案9. 核心规则与常见问题

1. 角色与数据权限

角色数据范围主要操作限制
管理员全量数据全部业务操作；维护基础档案、人员和币种；合同签约确认；收入实际删除。已被业务引用的基础档案建议停用，不可直接删除。
财务全量业务数据维护回款计划；登记到账与分配；管理收入计划和收入实际；维护目标预测。不承担合同制单和签约确认。
商务销售负责人为本人的合同及关联计划新建、编辑、提交、确认签约合同；查看本人合同及回款情况。不能登记到账、调整回款计划金额或维护收入实际。
商务助手本人录入或销售负责人为本人的合同及关联计划协助制单、编辑、提交、确认签约；查看本人范围收入与回款。不能登记到账、调整回款计划金额或维护收入实际。
权限口径：商务按照合同“销售负责人”判断；商务助手按“本人录入或销售负责人为本人”判断。代录并指定销售负责人后，对应商务可查看该合同。

2. 首页与经营驾驶舱

2.1 工作台首页

登录后系统默认进入经营驾驶舱；可从左侧菜单进入工作台首页。工作台用于集中查看待办、核心指标和高频入口，数据会随登录角色自动收口。

区域用途建议动作
今日待办提示合同、逾期回款、待确认收入等需要处理的事项。点击卡片进入对应列表继续处理。
核心指标查看合同、回款、收入、MRR/ARR 等概览。发现异常后进入驾驶舱或台账核对明细。
快捷入口按角色提供高频新建、登记和查询入口。用于日常制单或处理待办。

2.2 经营驾驶舱

  1. 在右上角选择统计月份，可按业务类型和成交模式筛选。
  2. 查看回款执行、收入执行、当月滚动预测以及 MRR/ARR。
  3. 收入趋势按实际确认收入统计，浅色为新客、深色为老客；若金额很小，柱体仍会保留最小可见高度。
  4. 客户签约贡献 TOP 5 按已签约合同含税金额累计排名；渠道、地区、SKU 和客户状态均可用于经营归因。
口径提示：驾驶舱“收入执行”= 当前筛选范围内的实际确认收入 ÷ 收入计划；未录入收入实际或金额很小都会显示为接近 0%。所有驾驶舱金额均已折算为人民币。

3. 客户管理

3.1 新建与查询

  1. 进入客户管理，点击“新建客户”。
  2. 填写客户名称，并按实际补充简称、国家/地区、行业、线索来源、统一社会信用代码和客户状态。
  3. 统一社会信用代码为空时，必须填写特殊创建原因；保存后客户才可用于新建合同。
  4. 列表可按名称/简称、行业、状态、线索来源及首签年度查询。

3.2 客户详情与导入

  • 双击列表非操作区域可打开客户详情，查看完整字段及合同总金额、累计回款、累计确认收入和合同数量。
  • “导入客户”先下载模板，再上传 .xls 或 .xlsx；导入重复客户不会覆盖历史档案，会返回失败原因。
  • 合同首次签约后，如客户首签年度为空，系统按该客户最早已签合同的签约年份自动回填。
删除限制：客户一旦产生合同即不能删除。需停止使用时，请改为停用或保留历史状态。

4. 合同台账、双币种与附件

4.1 合同全流程

1. 新建空白合同、复制或本人模板
→
2. 表头客户、主体、服务期、双币种
→
3. SKU价格、税率、付款规则、收入方式
→
4. 附件草稿/双方盖章/其他版本归档
→
5. 签约提交、确认，生成计划

4.2 合同台账

  • 进入合同台账，可按关键词、状态、业务类型、签约主体、签约日期区间筛选。
  • 列表默认按签约时间倒序展示；可切换为时间正序。合同名称不再作为列表列展示，合同类型与关联框架合同位于列表末端。
  • 双击合同记录或点击“详情”进入详情页；“更多”中可执行复制、提交、撤回、确认签约、撤销签约和生成回款计划等操作。
  • 合同编号和合同名称可留空，系统会根据签约主体、客户、业务类型与服务期自动生成。

4.3 新建合同与 SKU 明细

  1. 填写客户、签约主体、业务类型、合同类型、成交模式、销售负责人、服务起止日期和签约日期。
  2. 成交模式为直销时销售负责人必填；代理模式需选择代理公司；平台模式需选择平台主体。
  3. 普通合同或执行订单需添加 SKU，填写数量、未税单价、税率、服务期、付款规则、收入方式和经常性标记。
  4. 系统自动计算不含税金额、税额和含税金额；SKU 服务期必须落在合同服务期内。
  5. 框架合同用于管理框架额度；执行订单需关联框架合同，并与框架合同保持客户及关键表头信息一致。

4.4 双币种规则与详情展示

合同支持签约币种与结算币种分离，并分别记录两段汇率。详情页会同时展示签约额、结算额及人民币参考额，避免将不同口径混在一个金额中。

字段含义计算规则
签约币种合同 SKU 单价、含税总额的原始币种。合同含税额以此口径生成。
结算币种回款计划、到账分配与未回款的业务结算口径。结算金额 = 签约金额 × 签约→结算汇率。
结算→人民币参考汇率驾驶舱、预测和报表人民币折算口径。人民币参考额 = 结算金额 × 结算→CNY 汇率。
示例：若签约币种为 USD、结算币种为 CNY，签约含税额为 1,000 USD，签约→结算汇率为 7.20，则结算额为 7,200 CNY；结算币种为 CNY 时，结算→CNY 参考汇率固定为 1。

4.5 合同附件

  1. 在合同详情的合同附件区域点击“上传附件”。
  2. 选择附件阶段：合同草稿、双方盖章或其他；选择文件并填写说明后上传。
  3. 支持 PDF、PNG、JPG/JPEG、DOC/DOCX、XLSX，单文件最大 20 MB。
  4. 同一合同、同一附件阶段会按版本号保留；可下载有效版本，管理员/有权限用户可作废旧版本。
  5. 确认签约前，优先上传“双方盖章”附件；如确有例外，可在签约确认时填写例外原因，系统会留存审计记录。
附件存储：当前环境将附件存入服务器 Docker 附件卷，数据库仅保存文件元数据和存储键。生产部署时应将附件卷与数据库一起备份；长期生产环境建议规划私有 OSS 对象存储。

4.6 合同状态

状态说明典型操作
草稿尚未提交签约确认。编辑、删除、复制、存模板、提交。
待签约已提交，等待业务端确认。商务、商务助手或管理员确认签约；可撤回继续编辑。
已签约已确认签约日期。生成回款计划；后续进入回款、收入和看板统计。

5. 回款管理与到账通知单

5.1 生成回款计划

  1. 合同已签约后，在合同台账或回款管理点击“生成回款计划”。
  2. 选择尚未生成计划的已签约合同，系统依据 SKU 付款规则生成计划草稿。
  3. 确认计划日期、比例和金额后提交。回款计划金额为结算币种口径，并记录人民币折算额。
付款规则生成方式说明
一次性生成 1 期。金额为 SKU 含税金额，按规则基准日和账期计算计划日。
按月按服务期自动拆分。末期自动吸收尾差，确保计划合计准确。
按季按服务期覆盖的自然季度拆分。末期自动吸收尾差。
里程碑生成待拆分记录。由财务按实际节点补充日期、比例或金额。

5.2 计划维护与到账分配

  • 顶部指标展示当月计划回款、当月实际到账、逾期未回和未来计划回款；支持筛选及 CSV 导出。
  • 财务/管理员可编辑尚未到账的计划，或填写原因将计划作废；已有实际到账的计划不可编辑或作废。
  • 点击“到账分配”登记一笔到账，可分配至一个或多个同币种回款计划。选择计划后，系统默认填入“到账余额与计划剩余金额中的较小值”。
  • 外币到账需填写实际汇率；到账金额可暂不全分配，并在“未分配到账”中继续分配。

5.3 到账通知单

从回款管理进入到账通知单，可按到账单查看到账日期、金额、未分配余额、银行流水号、状态及分配明细，并可导出 CSV。退款或冲回会保留原始到账及更正说明，保证可追溯。

6. 收入管理

6.1 收入计划

收入计划根据合同 SKU 的收入方式生成。按月确认的 SKU 以服务开始日作为首期确认日，并按服务期均摊；一次性确认的 SKU 按其确认规则生成。末期自动吸收小数尾差，保证计划合计与合同不含税金额一致。

6.2 登记与调整

  1. 进入收入管理，按合同号/客户/SKU、状态和计划确认日期查询。
  2. 财务或管理员可选择一条或多条计划，登记实际确认收入；也可批量按计划剩余金额登记。
  3. “管理计划”可调整尚无实际的计划确认日和金额，必须填写调整原因。系统会联动同一 SKU 末期计划以保持总额一致。
  4. “管理实际”可编辑或撤销已登记的实际收入；操作必须填写原因。撤销生成负数冲回记录，历史不被物理覆盖。
重要区分：回款是资金到账，收入是履约确认。两者可以发生在不同日期、金额也可能不同，必须分别处理。

7. 预测与目标、报表中心

7.1 预测与目标

  • 进入预测与目标，选择月份后维护回款目标及滚动预测。
  • 目标冻结后应作为当期考核口径；实际回款和实际收入会从业务台账自动汇总，用于与目标、预测对比。
  • 金额按人民币统计，适合用于月度经营复盘。

7.2 报表中心

  • 合同分析支持按关键词、业务类型、成交模式、合同类型等筛选已签约合同。
  • 报表展示含税金额、已回款、未回款等人民币口径，并支持导出。
  • 点击“穿透”可查看合同关联的回款计划、到账、收入计划与收入实际记录。

8. 基础档案

基础档案由管理员维护。仅启用状态的档案可用于新业务制单；已被业务引用的数据应停用而不是删除。

档案主要用途
SKU 管理维护 SKU 编码、名称、业务大类/细分、默认税率、收入方式及经常性标记。
付款规则维护一次性、按月、按季、里程碑等收款规则，供 SKU 行选择并冻结快照。
签约主体、代理公司、平台主体管理合同可选主体及成交模式关联对象。
角色/权限、组织架构、人员管理账号、部门、销售人员与菜单/数据范围。
币种管理维护合同、计划和到账可使用的币种。已使用币种建议停用而非删除。
数据字典维护国家/地区、客户行业、线索来源、渠道名称、客户状态、业务分类等下拉选项。
管理核算规则维护管理核算相关规则，用于合同 SKU 的管理核算金额计算与追溯。
快照原则：SKU 税率、付款规则等会在合同/明细保存时冻结。后续修改基础档案只影响新业务，不直接覆盖已签约合同和历史计划。

9. 核心规则与常见问题

9.1 制单前检查清单

  • 客户、SKU、付款规则、签约主体和币种均已启用。
  • 合同服务期、SKU 服务期和签约日期已核对。
  • 成交模式与销售负责人/代理公司/平台主体匹配。
  • 签约币种、结算币种及两段汇率的方向正确。
  • 双方盖章合同已上传，或已准备合规例外原因。

9.2 常见问题

现象原因与处理
上传附件失败确认文件类型和大小符合限制；若仍失败，检查服务器附件存储目录/对象存储的写入权限，并保留错误信息供运维排查。
合同详情金额看起来不一致先确认查看的是签约、结算还是人民币参考口径。回款计划和回款实际以结算币种为准，驾驶舱/报表按人民币折算。
收入执行显示 0%检查该月是否录入收入实际；若实际额远小于收入计划，四舍五入后可能显示为 0%。可在收入管理查看明细。
无法编辑或作废回款计划计划已有实际到账时不可直接改写。请按到账冲回、更正或补充计划的业务流程处理。
基础档案无法删除该记录已被客户、合同或计划引用。请停用，不要删除历史事实。

9.3 日常建议

  1. 每次发布或结构迁移前，同时备份 MySQL 数据库和附件存储。
  2. 每月先核对回款计划与到账分配，再登记收入实际，最后更新预测目标并复核驾驶舱。
  3. 生产环境应使用独立强密码、HTTPS、定期数据库备份和附件备份；长期运行建议使用私有 OSS 保存合同附件。
